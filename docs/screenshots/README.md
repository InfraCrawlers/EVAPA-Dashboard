Screenshots directory

Place dashboard screenshot images or SVG placeholders here using the naming conventions documented in the project README.

Included placeholder files (you can replace with real screenshots):
- overview-desktop.svg
- vulnerabilities-desktop.svg
- vulnerabilities-mobile.svg
- assets-inventory.svg
- history-report-20250316.svg

Capture tips:
1. Start the app: `npm start`.
2. Use a 1920x1080 browser window for desktop screenshots.
3. For mobile captures, use Chrome/Edge/Firefox device emulation.
4. Keep filenames lowercase and replace spaces with `-`.
5. You may use PNG or SVG; SVG placeholders are present so the README shows images until you add real screenshots.

How to include in README or docs:

```markdown
![Overview desktop](docs/screenshots/overview-desktop.svg)
```
